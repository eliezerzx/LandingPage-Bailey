# Bailey Aplicativos - Landing Page

Landing page institucional desenvolvida para apresentar as soluções do ecossistema Bailey, destacando o módulo de **PDV Frente de Caixa** e suas funcionalidades essenciais para o comércio de alimentos e delivery.

## 🚀 Funcionalidades Demonstradas
* **PDV Frente de Caixa:** Gerenciamento ágil com simulação de telas em múltiplos dispositivos (Desktop e Mobile).
* **Emissão de Nota Fiscal:** Demonstração visual de impressão automatizada de cupons e notas fiscais.
* **Hub de Integrações:** Conexão direta com plataformas de delivery (iFood, 99 Food) e Cardápio Digital.

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3 (Layout responsivo e estilização moderna com tema escuro)
* JavaScript / Tampermonkey (Otimizações de performance e automação de workflow)
